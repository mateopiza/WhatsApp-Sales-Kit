# Storefront UI Kit

Interactive recreation of the Empires Jewelry e-commerce storefront (home, category/PLP, product detail, cart drawer). Original design (no source codebase/Figma was provided — see root readme Caveats), built from the design system's tokens and components.

Screens: `Header.jsx`, `Footer.jsx`, `HomeScreen.jsx`, `CategoryScreen.jsx`, `ProductScreen.jsx`, `CartDrawer.jsx`, assembled in `index.html`.
